# 🌉 CrossChain Wallet

A modern, open-source cross-chain wallet that enables users to manage and transfer assets across multiple blockchains — both **EVM-compatible** and **non-EVM** chains like **Casper** and **Solana** — through a unified, secure interface.

---

## 🚀 Features

- ✅ **Multi-chain support**: Interact with Ethereum, Polygon, Solana, and Casper.
- 🔒 **Secure key management** using industry-standard cryptographic practices.
- 🔁 **Cross-chain transfers** with a seamless user experience.
- 🔗 **Interoperability layer** to abstract chain-specific differences.
- 📱 Intuitive **React-based frontend** with responsive design.
- ⚙️ Modular architecture to support easy integration of new chains.

---

## 🛠️ Tech Stack

| Layer          | Technology                        |
|----------------|------------------------------------|
| Frontend       | React, TypeScript.     |
| Wallet Core    | Web3.js / Ethers.js, Solana Web3, Casper JS SDK |
| Cross-chain Logic | Custom SDKs / Adapters for each chain |
